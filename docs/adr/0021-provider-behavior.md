# Providers are profiled; immutable responses are cached; concurrency is bounded

Each provider has a profile with endpoint, auth reference, capabilities, rate limit, timeout, and retry policy. The RPC cache namespace includes the endpoint and chain ID, and keys include the method, normalized parameters, and block number or tag; immutable pinned-block responses are cached, while `latest` header, code, storage, and call reads are always re-fetched and are not written into the cache. Retries apply only to 429, 5xx, and timeouts, with exponential backoff and a configurable attempt limit. Stages run sequentially with a rate limiter per provider and per-dossier request budgets, so concurrency is bounded by construction rather than by a worker pool. This prevents 429 storms, keeps `latest` data from masquerading as historical evidence, and makes repeated research reproducible.
