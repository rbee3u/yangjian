# Targets come from a curated evidence-backed registry or explicit input, never generated addresses

Protocol entrypoints are seeded from `targets/<network>.json`, where each entry records the protocol, chain, addresses, official documentation URL, retrieval date, and notes; the CLI also accepts an explicit address from the user. The tool never synthesizes an address from model memory or name matching. M2 discovers pools and related contracts from the seeded factory through on-chain reads and events. Dynamic search may suggest candidates, but a suggestion is never written into the registry without evidence. This satisfies the no-guessing rule, makes seed data auditable, and still allows discovery to be evidence-driven.
