# Solc runs as a pinned binary in a path-jailed temporary directory with resource limits

Source artifacts are compiled by a pinned solc build downloaded from solc-bin and verified by hash. Each compilation runs in a fresh temporary directory with `--base-path` and `--allow-paths` restricted to that directory, a timeout, and memory/CPU limits; compiler diagnostics are parsed even when the process exits zero. Foundry and Slither are not invoked in M1, and project scripts are never executed. High-risk source trees may use a container profile with networking disabled. Solidity is not executed by solc, but hostile import paths, oversized inputs, and output rendering still require isolation and size limits.
