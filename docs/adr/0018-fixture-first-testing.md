# Tests are fixture-first and offline by default

`go test ./...` runs offline against a recorded Sourcify response, fake RPC responses, and golden JSON; live integration tests are gated by `YANGJIAN_LIVE=1`. The acceptance fixture pins the block number, block hash, runtime bytecode, and raw Sourcify response for the Uniswap V3 Pool. Live-only tests would make the suite flaky and network-dependent, while mock-only tests would never catch provider or schema drift. Fixtures make schema changes visible in review and keep the evidence path reproducible; the gated live suite catches the drift that fixtures cannot.
