# External data access goes through replaceable adapters; archive access is deferred

The MVP starts without an RPC key, while historical state and old transaction traces require archive-capable providers. All chain, source, trace, and analysis access will sit behind replaceable adapters with configurable profiles; metadata APIs that receive only public identifiers are acceptable; self-hosted nodes are optional. Free-tier keys may later be added to unlock historical state reads, but they do not include debug/trace APIs; historical-trace acceptance remains deferred until a paid or trial trace provider is introduced. MVP acceptance focuses on source provenance, current deployment topology, and current-state reads. This keeps the research workflow honest instead of substituting recent or simulated data for unavailable historical evidence.
