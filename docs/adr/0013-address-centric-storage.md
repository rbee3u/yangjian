# Research storage is address-centric, with protocol dossiers referencing contracts

Contract dossiers live at `research/<chain-id>/contracts/<address>/`; protocol dossiers live at `research/<chain-id>/protocols/<slug>/` and reference contract dossiers by `(chain ID, address)` instead of copying them. Address is the most stable on-chain key and shared contracts (USDC, WETH, routers) appear across many protocols. A protocol-centric tree would duplicate those contracts and assume a protocol identity before discovery; a flat content-addressed store would be unreadable and diff-hostile. This layout keeps M1 and M2 composable and Git-friendly.
