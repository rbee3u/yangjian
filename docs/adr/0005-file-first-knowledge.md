# Research knowledge is file-first and Git-versioned, not database-first

Structured research facts will be stored as canonical JSON records, narratives and diagrams as Markdown/Mermaid, all inside a per-target directory and versioned with Git. SQLite may later serve as a derived index for cross-research queries and RPC response caching, but JSON remains the source of truth and the database must be rebuildable. A graph database or vector store is rejected for the MVP: the research corpus is small, evidence must be exactly traceable, and semantic similarity is not evidence. This keeps artifacts readable, diffable, hand-repairable, and directly consumable by the coding agent.
