# Research knowledge is file-first and Git-versioned, not database-first

Structured research facts will be stored as canonical JSON records, narratives and diagrams as Markdown/Mermaid, all inside a per-target directory. SQLite may later serve as a derived index for cross-research queries and RPC response caching, but JSON remains the source of truth and the database must be rebuildable. A graph database or vector store is rejected for the MVP: the research corpus is small, evidence must be exactly traceable, and semantic similarity is not evidence. This keeps artifacts readable, diffable, hand-repairable, and directly consumable by the coding agent. The file-first layout is unchanged, but ADR 0025 narrows the Git-versioning claim: full `research/` dossiers stay local, while targets, fixtures/golden files, schemas, and design artifacts remain versioned.
